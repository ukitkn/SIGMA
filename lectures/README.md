# SIGMA execution-explanation presentation

Live page: <https://ukitkn.github.io/SIGMA/>

This ten-minute presentation follows the course report revised on 23 October 2026.
It presents five selected computational states, with concise What / Changes / Why
explanations. The first 2½ minutes introduce the healthcare problem and approach;
the ending explains the key finding, project lessons, limitations and future work.
Full speaking notes remain in [PRESENTER_NOTES.md](PRESENTER_NOTES.md), outside the
webpage. No video is required.

## Run and present

Use Python 3.11+ from the repository root:

```bash
python -m pip install -e '.[lectrace]' 'lectrace==1.1.30'
lectrace serve lectures/01_sigma_execution.py
```

Use the viewer's arrows to step through the selected code. `F` enters fullscreen;
`E` toggles the variable panel. The webpage replays a trace generated by running
Python during the build; it does not train a model in the teacher's browser.

## Relation to the report

The report uses eight colon/liver sections with 31,296 spots and 36,601 gene
features per section. Its original data and experimental scores are separate from
this synthetic teaching example. The table CSVs and [report_reference.json](evidence/report_reference.json)
record the report's numbers, conclusion and exact Software 3.0 disclosure.
[Evidence notes](evidence/README.md) distinguish the three comparison settings.

The executable example uses:

- 60 synthetic spots on a 6 × 10 grid with smoothly varying expression programs,
  synthetic patch descriptors and one
  illustrative CXCL12/CXCR4 interaction. No real H&E image is analyzed and no
  CellPhoneDB significance test is performed in the teaching run.
- Total-count normalization to 10,000 and `log1p`. All genes in the small teaching
  panel are retained, including the report's EMT/ECM programs.
- Symmetric eight-nearest spatial candidates. Physical edge weights combine
  spatial and morphology distances using the report's median-scale formula.
  CCC uses 30 receptor shuffles, positive z-scores and symmetric top-eight edges.
- The repository's MCGAE-inspired base, three residual GCN layers with LayerNorm,
  dropout 0.2 and concat + Linear + ReLU fusion. Reduced hidden/latent widths
  (16/8), three clusters and 80 epochs keep the teaching trace inspectable. The
  report's reference settings use hidden/latent widths 64/32, 20 clusters and at
  most 400 epochs. Optional Jumping Knowledge is disabled in both configurations.
- One visible extra Adam update on expression and CCC losses (weights 1.5/0.1).
  The hidden 80-epoch trainer uses the report's full loss families and weights.
  The visible update uses all unordered pairs and deterministic evaluation mode
  with autograd; full training samples edges and uses dropout/VAE sampling.
- Cluster centers initialized on the trained teaching embedding for the displayed
  Student-t checkpoint. Marker programs use the report's IFITM1/SNHG6 (tumor), IGFBP7/VIM/LGALS1
  (F/S) and ZG16/ITLN1/CLCA1 (normal/other). These annotations are separate
  from cluster IDs and do not provide independent validation of those IDs.
- Tumor-only Leiden at resolution 0.4, the report's explicit EMT/ECM gene sets,
  state-median early scores and a within-state rank-sum root. PAGA summarizes
  state connectivity; DPT uses 20 neighbors on the full embedding graph. Missing
  anchors fail explicitly; unreachable spots are excluded without a rank fallback.
- Projection onto the normal/other-to-stroma centroid axis, a centered 31-spot
  moving average and Gaussian interpolation on an 80 × 80 grid with bandwidth 80
  in input coordinates. Up to 80 neighbors are used (60 here). The figure shows
  progression intensity P, complementary potential U = 1 − P and directions
  F = −∇U = ∇P. Gradients use the actual grid spacing.

The report-specific graph and downstream reference constructions are in
[_report_protocol.py](_report_protocol.py); model training and interpolation reuse
`src/sigma`. These teaching helpers do not silently change the main pipeline's
existing defaults or claim to rerun the original experiments.

## Build and verify

```bash
lectrace build lectures/01_sigma_execution.py --output _site --no-incremental
python scripts/verify_lecture.py
```

The checks reject recorded exceptions, incomplete state/figure sets, disagreement
between CSVs and the report reference, stale method descriptions and missing report
results. The execution checks a real loss/embedding update, normalized assignments,
a tumor-state root and finite DPT. GitHub Actions runs the same build and verifier
before publishing GitHub Pages.
