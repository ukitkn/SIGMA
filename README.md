# SIGMA: Spatial Graph Learning for Tumor Invasion Analysis

SIGMA is a reproducible Python workflow for spatial transcriptomics. It combines an MCGAE-style graph autoencoder with spatial and ligand–receptor communication views, then analyzes tumor and stromal compartments, tumor subtypes, and a spatial invasion progression field.

The repository contains a complete implementation of the workflow described in the project materials. Historical lab scripts and trained weights were not available when this implementation was prepared, so this code defines a clean, internally consistent reconstruction. Metrics must be generated by running the pipeline on the original data; historical paper values are not bundled as if they had been reproduced.

## Workflow

1. Load an AnnData `.h5ad` file and validate spot identifiers and spatial coordinates.
2. Filter genes, select up to 3,000 highly variable genes, normalize to 10,000 counts per spot, and apply `log1p`. The full-gene normalized matrix is retained for marker and ligand–receptor scoring.
3. Construct a spatial k-nearest-neighbor graph. Build the communication graph from ligand–receptor pairs on spatial candidate edges, score both ligand-to-receptor directions, estimate a permutation background by shuffling receptor profiles, retain significant edges, and sparsify each node to its strongest partners.
4. Train an MCGAE-inspired multi-view graph autoencoder. It encodes original and corrupted expression over the spatial graph, a variational feature view, and a cosine expression-neighbor graph; attention fuses these views into the base representation. Separate spatial and ligand–receptor communication encoders then produce `X_sigma`. Expression reconstruction, VAE reconstruction and KL, spatial edge reconstruction, DEC-style clustering, communication edge reconstruction, contrastive learning between original and corrupted views, and spatial smoothness losses are optimized jointly.
5. Assign marker-based cell-type and tumor/stroma labels, compare expression-PCA, base, and fused embedding Leiden partitions, cluster tumor spots at the configured Leiden resolution, and retain raw clustering metrics separately from majority-mapped descriptive metrics.
6. Compute centered EMT and ECM scores, fibroblast distance, a marker-guided early root, PAGA connectivity, and DPT progression. The root is set to zero and progression is oriented from low to high DPT.
7. Smooth the spot-level progression over the tissue coordinates with a Gaussian Nadaraya–Watson estimator. Save the scalar field and its spatial gradient, using the actual grid spacing.
8. Optionally compare the inferred progression with an externally generated Slingshot pseudotime table by matched spot ID.

## Input files

Place the data files in `data/` or change their locations in `config/default.yaml`.

Place the Seurat `.rda` objects in `data/`; raw datasets are excluded from version control. The conversion command below exports the raw `Spatial` assay counts, the Visium pixel coordinates, and Seurat metadata such as `ident.annot` into an AnnData file. If another assay is required, pass its name with `--assay`.

The resulting AnnData file must contain:

- `adata.X` or a configured counts layer with non-negative count-like expression values.
- `adata.obsm["spatial"]` with two-dimensional spot coordinates.
- Optionally, a ground-truth annotation column such as `adata.obs["ident.annot"]`.

The ligand–receptor CSV must include columns named `ligand` and `receptor`. CellPhoneDB complexes are encoded as subunit symbols joined by `&`; a complex's abundance is the minimum abundance among its subunits. The communication graph uses the curated CellPhoneDB interactions as a resource and estimates spatial edge scores; it does not run the CellPhoneDB statistical inference pipeline.

## Installation

Python 3.10 or newer is required. Install the project into a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

For GPU training, install a PyTorch build that matches the CUDA version on the machine before installing this package.

## Run the pipeline

Export a Seurat object and create the gene-pair table from a downloaded CellPhoneDB release:

```bash
sigma convert-rda --rda-input data/ST-colon1.rda
python scripts/build_cellphonedb_lr.py \
  --database ~/Downloads/cellphonedb \
  --output data/cellphone_lr_pairs.csv
```

The converter selects the `Spatial` assay when it exists and writes the configured AnnData path (`data/processed/ST-colon1.h5ad` by default). R and the Seurat R package are required for this conversion. The CellPhoneDB builder accepts either an extracted directory or a downloaded zip archive; download a CellPhoneDB database bundle separately before generating the ligand–receptor CSV. The builder records the selected source, pair counts, and release status in a sidecar metadata file. If the source bundle does not identify its release, the metadata records that the release is unknown.

To convert all four colon and four liver RDA objects, run `bash scripts/convert_all_datasets.sh`. Change `data.input` in the configuration when switching samples.

After these inputs are present, run:

```bash
sigma run --config config/default.yaml
```

The workflow can also be run in stages:

```bash
sigma prepare --config config/default.yaml
sigma train --config config/default.yaml
sigma analyze --config config/default.yaml
```

Run the eight-configuration depth and communication/fusion ablation with:

```bash
sigma ablate --config config/default.yaml
```

Compare a Slingshot result exported as a CSV containing `spot_id` and `pseudotime`:

```bash
sigma compare-slingshot --config config/default.yaml --slingshot-csv results/slingshot.csv
```

## LecTrace presentation demo

`lectures/01_sigma_execution.py` is a 10-minute, five-state walkthrough of the SIGMA computation. It covers the healthcare motivation, spatial and expression graphs, a ligand–receptor communication graph, dual graph message passing with attention, and a downstream invasion-associated score. Its five-spot example is synthetic teaching data; the values are not measurements or performance results from the colon samples.

LecTrace requires Python 3.11 or newer. Install its optional dependency and start the interactive viewer from the repository root:

```bash
python -m pip install -e ".[lectrace]"
lectrace serve lectures/01_sigma_execution.py
```

The presenter notes include suggested timing and talking points. The `@inspect` and `@stepover` directives keep the variable panel focused on the five selected execution states. The script also runs with ordinary Python for a text-only preview:

```bash
python lectures/01_sigma_execution.py
```

The interactive presentation is published at <https://ukitkn.github.io/SIGMA/>. The source repository remains private; the deployed lecture page is publicly viewable and contains only the synthetic teaching trace.

## Output files

The default output directory is `outputs/ST-colon1/`:

- `prepared.h5ad`: normalized input, selected genes, spatial, expression-neighbor, and communication graphs.
- `embeddings.h5ad`: `X_sigma`, base and view embeddings, and model cluster assignments.
- `sigma_model.pt`: trained model weights and model configuration.
- `training_history.csv` and `training_summary.json`: objective values and run settings.
- `analyzed.h5ad`: marker labels, tumor subtypes, root scores, and invasion progression.
- `evaluation_metrics.json`: ARI, NMI, AMI, and majority-mapped descriptive metrics when reference labels exist.
- `spatial_invasion_field.csv`, `.npz`, and `.png`: interpolated progress, complementary potential, and gradient field.
- `ablations/`: per-configuration outputs and a summary table for the eight-run ablation.

The raw clustering metrics are the primary partition-comparison metrics. Majority-mapped values use the same reference labels to construct the mapping and are reported separately; they are descriptive and are not independent held-out prediction estimates. The spatial field is an inferred static tissue snapshot and should not be interpreted as a measured physical velocity or force.

## Configuration notes

The default training settings follow the available project materials where those settings were explicit: 3,000 HVGs, total-count normalization to 10,000, latent dimension 32, three graph layers, dropout 0.2, Adam at 0.001 with weight decay 0.0005, up to 400 epochs, cluster-loss warm-up at epoch 60, and a cosine learning-rate schedule. The implementation fixes the embedding path so that downstream analysis uses the fused spatial–communication representation. It also uses patience-based early stopping and records the selected checkpoint.

All code comments and user-facing project documentation are written in English. Large RDA files and derived datasets are excluded from version control.
